# MontaSpace Studio v0.1.0 — Windows verification

- [ ] Run `.venv\Scripts\python.exe main.py` in `montaspace2`.
- [ ] Title and About dialog say **MontaSpace Studio 0.1.0**.
- [ ] Add, move, resize, rotate, crop and layer photographs.
- [ ] Alt + left-drag moves the window. Window edge/corner resize feedback works.
- [ ] Open legacy `.mspace` photo projects and `.mspacepack` portable projects.
- [ ] Save/reopen Studio photo-only projects.
- [ ] Run `build_installer.bat`; output is `installer-output\MontaSpaceStudio_Setup_0.1.0.exe`.
- [ ] Install Studio. Confirm Start menu entry **MontaSpace Studio** and independent installation path.
- [ ] If MontaSpace is also installed, confirm both launch independently.
- [ ] Uninstall Studio and verify original MontaSpace and user documents remain untouched.

Video insertion and A–B looping are **not** part of this foundation version.
