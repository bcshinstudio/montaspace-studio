# Studio v0.2.0 Windows test checklist

- [ ] Studio shows version 0.2.0.
- [ ] Image-only existing projects open/save as before.
- [ ] Right-click > Insert > MP4 Video works.
- [ ] Drag/drop MP4 works.
- [ ] Video can be moved; Ctrl+wheel resizes selected video.
- [ ] Playback dialog plays/pauses, seeks, jumps ±5s; displays duration.
- [ ] Right-click video can reopen playback controls.
- [ ] Saving a board with video is blocked with clear warning.
- [ ] New/open/discard stops playback and clears video.
- [ ] Original MontaSpace v0.8.3 unaffected.

Known out of scope: video persistence, embedded videos, A/B loop, Undo for videos, rotation/handles on videos.
